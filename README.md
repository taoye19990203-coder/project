# 审计整改报告生成器

将内控缺陷汇总表转换为审计整改报告第二、三章的 Word 内容，复用所选 Word 模板的字体、字号、段落、自动编号和四张统计图样式。

**仓库只含程序代码，不含审计原文件、Word 模板或生成报告。使用时请选择自己电脑上的 Excel 和原 Word 报告。文件仅在本机处理，不调用外部文档服务。**

## 下载与运行（Windows）

1. 点击本仓库页面的绿色 **Code** 按钮，选择 **Download ZIP**。
2. 在“下载”文件夹找到压缩包，右键选择“全部解压缩”。
3. 如果尚未安装 Python，打开 Windows 终端或 PowerShell 运行：

   ```powershell
   winget install -e --id Python.Python.3.12
   ```

   也可从 [Python 官网](https://www.python.org/downloads/windows/) 安装 Python 3.10 及以上版本，并启用 Python Launcher。
4. 双击解压目录中的 **启动程序.bat**。首次运行会自动建立虚拟环境并联网安装依赖。
5. 浏览器自动打开后，选择 `.xlsx` 缺陷汇总表和 `.docx` 原报告，点击“核对数据”，确认数量与审计期间，再点击“生成并下载 Word”。

程序运行时保留终端窗口，按 Ctrl+C 或关闭窗口退出。不要直接双击 HTML 文件。

## macOS / Linux

安装 Python 3.10 及以上版本后，在程序目录运行：

```bash
bash start.sh
```

或手动安装并启动：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

只监听本机地址。端口占用时可运行 `python app.py --port 8766`。

## Word 模板与输出

请选择与原报告结构一致的 Word：保留“内控审计整改情况详述”“滚动内审情况详述”两个正文标题、自动编号、各字段示例、每章两张统计图，以及后续“附件一”边界。程序不支持任意结构的报告模板。

- **仅第二、三章**：输出独立的可编辑 Word，章节从第二章开始，包含概述、4张统计图、流程标题及全部缺陷明细，使用正文的纵向页面、页边距和页脚。
- **在原报告中更新第二、三章**：更新这两章；封面、第一章、目录和附件保留模板原文，需要人工复核。
- 段落属性、字符属性、字体字号、加粗、缩进、段距、行距、标题编号与图表样式从模板复制；四张图表缓存及内嵌 Excel 数据同步更新。
- 在“审计期间与实体筛选”中填写新期间；留空时沿用所选模板的期间。多实体表必须填写完整实体名称进行筛选。
- 空缺内容会提示并标记“待补充”，不会编造审计意见。

请使用安装了“仿宋”等模板所用字体的 Microsoft Word 打开。字体缺失或使用其他 Office 软件可能导致显示和分页不同。内容长度改变也会自然改变分页，最终视觉效果请在目标 Word 中核验。

## Excel 规则

支持原缺陷表的双层表头，自动定位唯一明细表；数据行数可增减，隐藏行也参与处理。需要保留以下字段及“审计项目组反馈”栏：

| 报告内容 | Excel 来源 |
|---|---|
| 第二章（回头看） | 审计类别含“回头看”或“内控审计”，且不含“滚动” |
| 第三章（滚动审计） | 审计类别含“滚动” |
| 流程与问题标题 | 涉及业务流程、问题简述；各流程内重新编号 |
| 第二章【问题简述】 | 问题描述的首段，沿用原报告规则 |
| 第二章【整改结果】 | 项目组反馈的实际整改措施及结果 |
| 第二章【原因说明及后续计划】 | 项目组反馈的未整改原因说明及后续整改计划 |
| 第二章【整改情况】 | 项目组反馈的是否完成整改 |
| 第三章【问题描述】 | 完整问题描述，按换行分段 |
| 第三章【管理建议】 | 项目组反馈的未整改原因说明及后续整改计划 |
| 第三章【问题类别／等级】 | 原问题类别／等级 |
| 两章【责任部门／整改时间】 | 项目组反馈的整改责任部门／整改时间节点 |

第二章总体完成率统计全部缺陷，考核口径只统计“设计”和“执行”。百分比四舍五入取整数，分母为零时为“不适用”。整改状态需为“已整改”“整改中”“未整改”。问题类别需为“管理提升”“风险提示”“设计”“执行”；等级需为“重大”“重要”“一般”。日期转换为中文格式，多部门换行用分号连接。

缺少必要表头、问题标题或业务流程，或类别／等级／状态无法识别时，会提示具体行号并阻止生成。若 Excel 使用公式，先用 Excel 计算并保存，避免没有缓存结果而被视为空缺。

## 命令行

```bash
python generator.py 缺陷汇总表.xlsx --template 原报告.docx -o 输出/第二三章.docx
python generator.py 缺陷汇总表.xlsx --template 原报告.docx --mode full -o 输出/完整报告.docx
```

可通过 `--company` 筛选实体，`--original-period`、`--rolling-period` 指定审计期间。命令行同时保存 JSON 核对结果。输出路径不可覆盖输入文件。

## 验证

```bash
python -m unittest discover -s tests -v
```

测试数据和测试模板由代码生成，不含实际审计资料。覆盖字段映射、分段、字体与段落属性、编号、统计图及内嵌数据同步、空值提示、多实体筛选、完整模式保留其他章节，以及上传与下载接口。

本地的 `templates/`、`examples/`、Office 文件及输出目录已加入 Git 忽略规则，避免将审计资料加入后续代码提交。
